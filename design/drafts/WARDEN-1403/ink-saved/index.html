Warden sidebar — Ink · Saved

state matrix · every view at 208 px and 320 px

The sidebar does four things, in this order: start a shell, reach a host, come back to a session you saved, and see git status. Everything a session needs to be findable is a name you gave it — so the list is short by construction, and the scanning problem the first round solved with colour and density is solved here by there being only a handful of rows to scan. Ink's row anatomy is unchanged: an identity chip, the name alone on the first line, and metadata on a second line that never competes with it.

Hosts are the primary navigation and carry their live count; collections sit beneath them, muted; git status is an add-on at the bottom. The spawn control shows exactly what it opens — a host, a directory and a shell — and nothing it cannot deliver.
